# Asset policy

## What never enters Git

- Source footage, client media, and any private recordings.
- Third-party reference media (frames, crops, snapshots, album art, soundtracks).
- Paid asset packs and licensed binaries.
- Rendered masters, intermediates, and QA output (these live under `output/`, gitignored).
- Fonts shipped as binary files, and any audio binary.
- Credentials, model keys, and `.env`.

`.gitignore` excludes `node_modules/`, `dist/`, `output/`, and `.env`. `.gitattributes` marks media extensions as binary as a second guard.

## Procedural assets only

The renderer and the demo use procedural visuals: CSS gradients, SVG shapes, and typography drawn in code. There is no stock imagery, no generic AI art, and no external image files. Demo audio is generated by FFmpeg's lavfi sources and normalized to the loudness target; no audio file is read from disk or bundled.

## Bring-your-own assets

A plan may reference supplied assets (source clips, B-roll, dialogue, music, and SFX) by portable relative path. The default root is `assets/` under the current project. A worker can override it with `OVE_ASSET_ROOT`. The engine:

- validates every path as relative, with no drive letter, absolute root, UNC, home expansion, or parent escape;
- confirms every declared file exists before the render starts;
- exposes only the configured asset root to Remotion's static-file server;
- never overwrites a source file;
- treats source media as read-only input.

## SFX and licensing

- The blacklisted asset `impact_ultra_serious_48k_pcm24.wav` and its pitched, stretched, layered, or renamed derivatives are rejected by the SFX gate and must never be used.
- The repository bundles no SFX. Real cues enter only through a rights-cleared manifest (`src/sfx/manifest.ts`).
- `checkManifestRights` rejects NonCommercial licenses for commercial work and treats NoDerivatives as unsafe for synchronization, and rejects any blacklisted asset present in a manifest.
- Each record keeps its source URL, license, license URL, and SHA-256. A downloaded file is verified against the manifest hash before use.
- `scripts/fetch-sfx.ts` is a mechanism, not a bundled library: it dry-runs by default, refuses without a manifest, and wires no network transport of its own.

## Music and rights

- Music is not automatic. Add it only when a brief or an approved series requires it.
- Verify music rights before rendering. Reject NonCommercial tracks for commercial work and treat NoDerivatives as unsafe for synchronization unless separately licensed. Save the license and source URL beside the asset.
- Public or official footage is not automatically cleared for reuse; flag permission requirements or replace it before public delivery.

## Metadata and privacy

- Deliverables strip inherited metadata (`-map_metadata -1 -map_metadata:s -1`).
- QA asserts no GPS or location tags survive on the delivered master. Phone clips can carry GPS, device model, and creation details; those must not ship.

## Provenance ledger

For any reconstruction work, keep a provenance record for every asset, one of: coded, procedurally generated, generated by a named model and prompt, user-supplied non-reference asset, or separately licensed source. Never harvest pixels or audio from a reference; the clean-room boundary is documented in `skills/shivank-social-video-editing/references/exact-reference-reconstruction.md`.
